# User Screenshots

This directory contains screenshots of the **Nexus SIEM System** user interface, illustrating the view available to security analysts and standard users.

## Screenshots

### 1. Security Overview
**File:** `Security Overview.png`
The user-facing dashboard tailored for monitoring assigned tasks and general security status.
- **Metrics:** Personalized or role-based counts for incidents and logs.
- **Recent Alerts:** Visibility into alerts relevant to the user's scope.

### 2. Security Logs
**File:** `Security Logs.png`
A focused view of security logs accessible to the user.
- **Log Analysis:** Users can view log entries (e.g., authentication events, system messages) relevant to their permissions.
- **Details:** Includes timestamp, severity, and message content for each log entry.

### 3. Security Incidents
**File:** `Security Incidents.png`
Displays security incidents that the user is authorized to view or manage.
- **Incident Tracking:** Lists active incidents with details such as severity ("Critical"), type ("Authentication Log"), and source information.

### 4. User Profile
**File:** `User Profile.png`
The user's personal account management area.
- **Profile Info:** Displays User ID, Access Level (e.g., "Analyst"), and Workspace details.
- **Responsibilities & Privileges:** Clearly lists what the user can do (e.g., "View logs," "Generate reports") and their managed areas.
- **Account Actions:** Options to reset password and view 2FA status.
