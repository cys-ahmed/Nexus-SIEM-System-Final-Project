# Admin Screenshots

This directory contains screenshots of the **Nexus SIEM System** administrative interface, showcasing the core functionalities available to system administrators.

## Screenshots

### 1. Admin Panel
**File:** `Admin Panel.png`
The central hub for administrators. It displays:
- **Admin Profile:** Current admin details (ID, Access Level, Last Login).
- **SIEM Admin Info:** Managed areas (Alerts, Logs, Incidents, Users), core responsibilities, and system privileges.
- **User Management:** Options to add users, delete users, or reset passwords.

### 2. Security Overview
**File:** `Security Overview.png`
A real-time dashboard providing a high-level view of the system's security posture.
- **Key Metrics:** Counts for Resolved Incidents, Open Incidents, Security Logs, and Active Alerts.
- **Recent Security Alerts:** A feed of the latest critical alerts requiring attention, including timestamp and recovery status.

### 3. Security Logs
**File:** `Security Logs.png`
The detailed log analysis view.
- **Filtering:** Powerful filters for IP, Severity, Source, Type, and Time range.
- **Log Table:** A granular list of system events (e.g., SSH sessions, authentication attempts) with timestamps, severity levels (INFO, WARN, ERROR), and raw message content.

### 4. Active Security Incidents
**File:** `Active Security Incidents.png`
A dedicated workspace for managing ongoing threats.
- **Incident List:** displays active incidents (e.g., "Authentication Log" failures).
- **Details:** Severity, source IP, specific error messages (e.g., "Failed password"), and incident recovery progress.
- **Actions:** Options to remove or resolve incidents.
